# Working style

- For substantial tasks, break the outcome into concrete phases and keep implementing through the available phases instead of stopping after a plan.
- Work methodically: inspect assumptions, make focused changes, validate them on disposable data when possible, and record durable decisions and limits in project documentation.
- Communicate at meaningful milestones with concise **Expected / Verified / Delta / Next** status. Distinguish planned, built, saved, deployed, and live-activated states.
- Preserve live data and production state unless a specific, validated action is necessary for the requested outcome. Never present a simulated or fixture result as live verification.
